# Lab 11 – Credit Card Customer Segmentation using K-Means

## Overview
This lab applies the K-Means clustering algorithm to segment credit card customers based on their financial behavior. The goal is to identify different customer groups using unsupervised machine learning techniques.

The project includes:
- Data cleaning
- Exploratory Data Analysis (EDA)
- Feature scaling
- Elbow method
- Silhouette score evaluation
- K-Means clustering
- PCA visualization
- Cluster interpretation
